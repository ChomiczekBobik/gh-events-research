# Нет, я не Краковянин

Пародия на *No, I'm not a Human*. Краков ударил по Величке ядеркой, пыль осела через неделю, и к тебе домой стекаются выжившие. Отличай **величанина**, **радиоактивного величанина** и **краковянина-предателя**.

Чистый HTML/JS без сборки. Музыка и звуки генерируются через WebAudio.

## Запуск локально

```
python3 -m http.server --directory docs
```

## Публикация на GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → `main` / `/docs`.

## Свои персонажи

1. Положи картинку в `docs/assets/characters/` (PNG, лучше с прозрачным фоном).
2. Добавь запись в `docs/characters.js` (там есть пример).

## Как играть

У каждой ночи ограниченное число проверок: дозиметр, фонарик, соль-тест, вопрос, документы.
Облучённые убивают жильцов радиацией, краковяне — ножом. Утром можно выгнать подозрительных жильцов.
